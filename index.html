02.Featured Graphics Work

FEATURED 01 · RENDERER

Trodo Engine

A custom graphics engine built from scratch in C++ and OpenGL, with its own rendering pipeline, material authoring and a real-time editor viewport.

  • Hybrid Deferred + Forward rendering pipeline
  • Physically based shading (PBR) with shadows
  • HDRI skybox
  • Node-based Material Editor inspired by UE5
  • Real-time editor Viewport with gizmos, Hierarchy, Inspector and Content Browser
  • Archetype ECS feeding the renderer, with a dirty-flag system so only changed objects update
  • C++
  • OpenGL
  • PBR
  • Shaders
  • ImGui
FEATURED 02 · LIGHTING & POST

Procedural Forest

A forest rendered in OpenGL: geometry generated procedurally, lit dynamically and finished with a stylised post-process.

  • Procedural meshes built as surfaces of revolution
  • Dynamic lighting across the scene
  • Cel-shading post-process effect
  • ImGui controls for real-time tweaking
  • C++
  • OpenGL
  • Post-process
  • ImGui
FEATURED 03 · PIXELS BY HAND

Particles & Pixels on Game Boy Advance

Two GBA projects with their core logic hand-written in ARM assembly, drawing pixel by pixel straight to the framebuffer — no API between me and the screen.

  • Sand: falling-sand particle simulation with per-particle update and gravity
  • Snake: movement, growth, collisions and rendering in assembly
  • ARM7TDMI, built with make and devkitPro on Linux
  • ARM Assembly
  • C
  • devkitPro
